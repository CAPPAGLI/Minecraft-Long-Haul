# Long Haul Legacy 2.0 — Transport Lab α1

**Технический прототип, НЕ завершённая сборка по полному ТЗ.** Импортируемый `.mrpack` предназначен для отдельного тестового профиля и нового мира. Рабочая 1.1.1 не изменена. До прохождения клиентского и транспортного тестирования не использовать для основного длительного прохождения.

## Что находится в пакете

- **Minecraft 1.20.1 / Forge 47.4.10 / Java 17.** Версия Forge закреплена: один из аддонов требует именно более нового Forge, чем первоначально выбранный 47.4.0.
- **62 внешних JAR + 1 собственный Long Haul Runtime**; библиотеки уже входят в это число. 73 объявленных mod ID с вложенными зависимостями — не 73 отдельных игровых системы и тем более не 500 модов.
- Create 6.0.8, Steam ’n’ Rails, Crafts & Additions, Enchantment Industry, Connected, Deco, Slice & Dice, Central Kitchen; дополнительные генераторы, оформление и железнодорожный навигатор.
- Valkyrien Skies, Clockwork 0.5.6 с вложенным Kelvin, Eureka, Trackwork; Immersive Aircraft, Man of Many Planes, Small Ships. Их наличие НЕ означает, что физика и управление уже проверены в клиенте.
- Farmer’s Delight, Brewin’ and Chewin’, CC: Tweaked/Advanced Peripherals, Exposure, Simple Voice Chat, Zume, Storage Drawers, карты, просмотр рецептов, QoL и базовые оптимизации.
- Tectonic, Terralith, Towns and Towers, YUNG’s Bridges; полной биомной и городской программы из проекта здесь ещё нет.
- **26 установленных квестов Heracles:** 6 информационных, 12 честно помеченных инвентарных учебных вех и 8 испытаний серверной приёмки. 240 записей в `design/quest-catalog.*` — отдельные спецификации, НЕ установленные квесты.
- Граница обычного мира 175000 блоков с центром 0,0 устанавливается скриптом при первом запуске. **Гарантии всех нужных объектов внутри неё ещё нет.**
- Космические моды и температурные моды не включены. DOOMED не включён: официальный источник и предупреждение об экспериментальности находятся в `DOOMED.md`.

Полный состав и хэши: `assembly/lock.json`, `MODLIST.md`. Подробности проверки: `TEST-REPORT.md`, машинный статус: `STATUS.json`.

## Установка тестового профиля

1. Скачайте `Long-Haul-Legacy-2.0-alpha.1.mrpack`. Не переименовывайте старую сборку и не накладывайте эту ветку поверх неё.
2. Импортируйте через совместимый с Modrinth-пакетами лаунчер, например Prism Launcher. Загрузка внешних модов идёт с Modrinth CDN; сами сторонние JAR в архив не перепакованы. Импорт лаунчером в этой среде не проверен.
3. Выберите **Java 17**. На машине с 32 ГБ RAM начните с **8 ГБ** для этого небольшого ядра; 10–12 ГБ — только если измерения покажут необходимость. Это стартовые рекомендации, не результат тестов на вашем ПК. Не выделяйте игре все 32 ГБ; файл подкачки не заменяет RAM.
4. Создайте **новый обычный мир**. Сохранение 1.21.1 нельзя понижать до 1.20.1. Не используйте тестовый void-мир из исходников для прохождения.
5. На первом входе выдаётся книга Heracles. `/lh help` показывает команды. Если книга не появилась — проверить ошибки KubeJS; повторная выдача книги не предназначена для обхода ошибок загрузки.
6. Для голосового чата на выделенном сервере обычно нужен отдельный UDP-порт; фактическую настройку смотрите в созданном конфиге Simple Voice Chat. Встроенный голос и соединение клиента здесь не тестировались.

Это клиентский профиль с отметками client/server в манифесте. **Не копировать все клиентские JAR на dedicated server вслепую.** Готового отдельного серверного дистрибутива в этом выпуске нет. Тестовые `server.properties`, offline-mode, loopback-привязка и уменьшенный heap НЕ поставляются в `.mrpack`.

## Проба серверной приёмки

1. Поставьте обычную пустую бочку в обычном мире и встаньте **на неё**.
2. Выполните `/lh terminal`, затем `/lh accept plates`.
3. Подайте 64 `create:iron_sheet` воронкой или транспортом Create. Приёмка **безвозвратно расходует** принятые товары. Они не возвращаются при провале или отмене.
4. `/lh status` показывает состояние. `/lh abort` отменяет активный заказ; остаток непринятых товаров остаётся в бочке.
5. Для испытания ритма: `/lh accept plate_shift` — 16 пластин в КАЖДОМ из трёх окон по 60 игровых секунд. Чанк должен оставаться загруженным. При низком TPS игровая минута дольше реальной.

Другие ID: `brass`, `rails`, `provisions`, `mechanisms`, `food_shift`, `rail_shift`. Нормы находятся в книге. У каждого игрока отдельная приёмка/прогресс; общей командной экономики пока нет. Каждый заказ даёт серверную квитанцию и advancement с 15 XP один раз. Проверка восстановления квитанций при настоящем переподключении игрока ещё нужна.

**Что именно доказывает испытание:** товары действительно извлечены из инвентаря терминала, соблюдены нормы окон приёмки. Оно НЕ доказывает изготовление на месте, расход топлива, скорость станка, конкретный поезд или пройденный маршрут. Поставка из запасов возможна. Открытие/обычное ломание активной бочки блокируется, но универсальной античит-защиты от взрывов, поршней, контрапций и всех модовых взаимодействий нет.

## CC: Tweaked

В ROM добавлена программа `longhaul_depot`. Пример: `longhaul_depot back create:iron_sheet 64 right` — показывает запас в подключённом инвентаре и включает сигнал справа при нехватке. Это **сигнализация запаса, не измеритель производства и не доверенный квестовый датчик**. Проверка на настоящем компьютере/периферии ещё требуется.

## Что делает собственный Runtime-мод

Он меняет радиус предварительной загрузки спавна с 11 до 2 и согласованно целевое число чанков с 441 до 9 в закреплённой версии сервера. Обычная загрузка мира, сохранения и чанки вокруг игроков не отключаются. Процент подготовки может выглядеть необычно: ванильный индикатор рассчитан на старый размер области.

Это **не** генератор городов, не запрет телепортов и не реализация всей системы инженерной проверки. Исходник: `runtime-mod/`. JVM-параметр `-Dlonghaul.spawnRadius=11` возвращает прежний размер подготовки. Не переносить JAR на другую версию Minecraft/Forge: инъекции намеренно проверяют точное совпадение; Forge ограничен 47.4.10.

## Незавершённые обязательные части

| Требование | Состояние α1 |
|---|---|
| Примерно 500 полезных модов | Не выполнено: ядро из 63 верхнеуровневых JAR вместе с нашим модом |
| Восемь культурно и производственно разных городов | Только проект; нет своих NBT, возобновляемой экономики и заданных импортов |
| Гарантии ресурсов/биомов/боссов и единичных объектов в ±87500 | Только размер границы; нужен реестр локаций и валидатор/генератор |
| Заброшенные заводы, восстановление мостов/портов/шахт | Нет готовых сцен и доверенной проверки восстановления |
| Полная многоступенчатая инженерная кампания | 8 ограниченных испытаний приёмки; 240 спецификаций не подключены |
| Поезда, маршруты, расход топлива, реальная производительность | Моды есть, доверенных датчиков и тестирования нет |
| Фотографическая глава с проверкой содержания кадров | Камера и учебные задания; содержание фото не проверяется |
| Ограничение ручного груза и вложенных контейнеров | Убраны рецепты шалкеров/эндер-сундука; это НЕ глобальный запрет получения, лута, переноса и вложения |
| Компактный неэксплуатируемый разворачиваемый лагерь | Не реализован; Comforts — только часть бытового оснащения |
| Отсутствие ранней телепортации | Специализированные телепорт-моды не выбраны; нет всеобъемлющего запрета ванильных и модовых возможностей |
| Готовность к долгому кооперативному прохождению | Не подтверждена; клиент, GUI, транспорт, обычный мир и долговременная нагрузка не проверены |

План целевой игры: `design/ПРОЕКТ-2.0.md`. Исторический аудит 347 прямых/404 расширенных кандидатов не является перечнем установленных или совместимых модов. Extended Cogwheels и Create Track Map исключены после обнаруженных бинарных конфликтов. Экспериментальные ServerCore/Fastload также не вошли в итоговый профиль.

## Воспроизведение

```bash
python3 tools/assemble_alpha.py     # интернет, 62 закреплённых внешних JAR
python3 tools/build_runtime.py      # установленный тестовый Forge + Java 17
python3 tools/inspect_alpha.py      # mod ID / обязательные ID, не полная проверка ABI
node tools/test_contracts.js        # 12 тестов модели
python3 tools/generate_alpha_quests.py
python3 tools/package_alpha.py      # только lock-selected файлы и чистые overrides
```

Запуск аудита кандидатов отдельно: `tools/audit_mods.py`, `tools/audit_create_jars.py`, `tools/audit_dependencies.py`. Срез выбора версий — **15.11.2026**; более поздние релизы не выбирались. Часы песочницы в логах могут отличаться от даты среза. Скрипт `smoke_server.py` — ограниченный исследовательский стенд, а не production launcher.
